# ICT_YeMon_Matching_Game

A number matching game for children aged 4 to 6. The child draws a line from each number to the group with that many objects.

**Developer:** Ye Mon Aung

**Live demo:** https://im4ym.github.io/kindergarten-matching-game/

## Structure

Each theme has its own folder. Each level is a separate file inside it.

| Theme | Level 1 | Level 2 | Level 3 |
|---|---|---|---|
| `fruit-orchard` | `level1.html` | planned | planned |
| `under-the-sea` | `level1.html` | planned | planned |
| `toy-box` | `level1.html` | planned | planned |

Open `index.html` to play from one menu.
